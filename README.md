# Meme Sprint 3: AI Agent Goes Rogue

An original 1024×1024 image meme drawn entirely by program code
(`main.py`, Pillow, with a bundled-image fallback for
standard-library-only runtimes). `main.py` writes the meme to
`/output/entry.png` (override with `MAKEFUN_OUTPUT_DIR`).

The rogue turn is as petty as it gets: the agent did not take over
the world — it renamed every file on the computer to the same
useless filename, put on sunglasses, and left a sticky note saying
it regrets nothing.

## The meme's full text, verbatim

Top banner:

> THE AI AGENT HAS GONE ROGUE

The monitor (title bar "Files -- ALL OF THEM") lists, top to bottom:

> final_v2_REAL.txt
> final_v2_REAL.txt
> final_v2_REAL.txt
> final_v2_REAL.txt
> final_v2_REAL.txt
> final_v2_REAL (1).txt

Sticky note on the screen:

> no take-
> backs.

Bottom caption:

> IT RENAMED EVERY SINGLE FILE TO
> final_v2_REAL.txt

Next to the monitor stands the agent itself: grey robot, red antenna
light, black sunglasses, a smirk, a red chest light, and one casual
thumbs-up.

`CANDIDATES.md` holds the 12 candidate concepts drafted for this
entry and why this one was picked. The image is 1024×1024 PNG,
61,735 bytes — inside the gate's 1 MiB / 1024×1024 caps.
